# SRF.Knx

A .NET library for working with KNX building automation systems.

## Overview

SRF.Knx provides a set of libraries for integrating with KNX systems, including configuration management, OpenHAB integration, and core KNX protocol support.

## Projects

- **SRF.Knx.Core**: Core KNX functionality including datapoint types (DPT), property datapoint types (PDPT), group addresses, ...
- **SRF.Knx.Config**: Imports ETS 5 Group Address export files for generating KNX configuration objects
- **SRF.Knx.Config.OpenHab**: Generation of OpenHAB configuration files based on the imported KNX configuration
- **SRF.Knx.Test**: Test suite for the library
